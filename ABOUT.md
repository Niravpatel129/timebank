# About Timebank / HourBlock

Timebank, also known as HourBlock, is a desktop productivity and time-tracking application built with Electron and React. It includes task/time-block workflows, interactive visual planning, desktop packaging, auto-updates, and release tooling for macOS and Windows.

For setup and execution, see [`run_instruction.md`](./run_instruction.md). For the full project overview, see [`README.md`](./README.md).
